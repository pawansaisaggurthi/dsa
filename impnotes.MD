/*
JavaScript Math Methods

1. Math.round(x)
   - Rounds a number to the nearest integer.
   - If the decimal part is < 0.5 → rounds down.
   - If the decimal part is ≥ 0.5 → rounds up.

   Examples:
   Math.round(10.3)  // → 10
   Math.round(10.6)  // → 11


2. Math.floor(x)
   - Always rounds **down** to the nearest integer (ignores decimal part).

   Examples:
   Math.floor(10.3)  // → 10
   Math.floor(10.6)  // → 10


3. Math.ceil(x)
   - Always rounds **up** to the nearest integer.

   Examples:
   Math.ceil(10.3)   // → 11
   Math.ceil(10.6)   // → 11


4. Math.abs(x)
   - Returns the absolute value (removes the sign).

   Examples:
   Math.abs(-256)    // → 256
   Math.abs(305)     // → 305
*/
